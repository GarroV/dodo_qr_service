# Block: library

## Назначение

Библиотека переиспользуемых блоков: блок заводится один раз и вставляется в любое число чек-листов, правится в одном месте. Механика, ради которой редактор перестаёт быть копипастой.

## Контракт

```ts
listBlocks(); getBlock(id); saveBlock(id, { title, items })
listUsages(blockId): Promise<{ checklistId; title; station; store; published: boolean }[]>
insertBlockIntoDraft(checklistId, blockId)
detachBlock(checklistId, sectionId)   // превращает вставленный блок в обычную секцию
```

## Зависимости

`editor`

## Definition of Done блока

1. Правка блока приходит во все черновики, где он вставлен, и **не меняет ни одной опубликованной версии** — тест сравнивает опубликованную версию до и после правки блока.
2. Перед сохранением видно, что затронет правка: сколько черновиков и сколько опубликованных версий.
3. «Где используется» перечисляет чек-листы со ссылками.
4. Отвязка блока превращает секцию в обычную, содержимое остаётся.
5. Блок, не вставленный никуда, помечен явно.
6. Экран совпадает с эталоном `docs/forge/design/screens/library.html`.
